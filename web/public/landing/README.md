# Landing placeholders

Replace these files with your own hero art, section backgrounds, or logos. Do **not** commit NCSoft / official Aion 2 marketing assets.

| File | Suggested use |
|------|----------------|
| `hero-placeholder.svg` | Full-width hero background (referenced from the landing page) |
| `class-bg-placeholder.svg` | Optional decorative panel (not wired yet — copy into CSS or components as needed) |

Recommended formats: SVG or WebP, optimized for dark backgrounds. After swapping files, keep the same filenames or update `LandingApp.tsx` paths.
