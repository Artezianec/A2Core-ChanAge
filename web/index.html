ChanAge · Aion 2 — fan test server

Non-commercial fan test server for Aion 2. Fly, fight and explore Atreia on the ChanAge test shard with the supported Steam client — no host file edits required.

How to start

  1. Register an account while registration is open.
  2. Sign in and download the A2Core Launcher for Windows.
  3. Point the launcher at the folder where Steam installed Aion 2, then launch and play.
